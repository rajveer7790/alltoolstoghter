# All Tools Together: audit implementation and remaining work

Revision: 16 November 2026. Repository baseline: `4a4a85c`. This is a source implementation record, not a claim of improved rankings, indexing, backlinks or Core Web Vitals.

## Findings checked against source and live HTML

The original homepage advertised 278 canonical tools, while About/Footer used 281 registry entries, including three aliases. The live homepage fetched before changes was 279,687 bytes uncompressed. A visible breadcrumb already existed. The site uses Next.js **static export**, not a running SSR application. Some recent tools already had sources and worked examples. The shortener and writing services are separate optional backend services; the old footer's universal local-processing claim was inaccurate.

The report's keyword volumes, competition levels, backlink absence, rank expectations and scorecard are not treated as verified measurements. We did not receive GSC/Bing performance exports or an account-level backlink report. Word count, SearchAction, robots declarations and llms.txt are not ranking guarantees.

## New tools delivered

Ten India-focused tools: EMI, SIP, GST, PPF projection, EPF projection, FD, RD, gratuity formula, HRA and an explicitly scoped **AY 2026–27 / FY 2025–26** income-tax comparison. Taxable income must be computed per regime; this is not a claim to implement unverified FY 2026–27 rules. Projections disclose assumptions and ₹ / lakh-crore number formatting.

Six additional utilities: PDF object-stream optimization, HEIC→JPEG conversion, random integer generator, coin flip, random name picker and typing-speed practice. PDF optimization retains original bytes if repacking is larger; it does not promise image downsampling. HEIC conversion is lossy, drops metadata and cannot decode every codec variant. Random selection uses rejection sampling over cryptographic random values.

## Operations and validation

- `npm ci`, `npm run check`, `npm run build`, `npm run audit:export` reproduce the main checks. `audit:export` checks canonical routes, links/assets, titles, descriptions, JSON-LD syntax, sitemap policy and maintained dates; it writes stable IndexNow fingerprints in the export.
- `scripts/preview-export.mjs` serves the built export for QA, including simple Netlify redirects and the two isolated widget variants.
- Do not reset content dates on each build. A source/content change should update its maintained revision deliberately; a content date does not mean all tax/medical rules were independently re-reviewed.
- Shortener: deploy the separate backend, set a canonical `PUBLIC_BASE_URL` and CORS origin; use exact moderated destination hosts or an eligible reputation provider. Google Safe Browsing has usage restrictions; commercial operators should use a licensed Web Risk adapter. Multi-process deployment needs shared storage/rate limiting. The included JSON store is for one process on durable storage, not an ephemeral scaled deployment.
- Moderate aliases through `SHORTENER_APPROVED_ALIASES`. Reports are saved in the backend's ignored `data/link-reports.json`. Disable a reviewed harmful record by setting `disabled: true` through the store interface. Do not expose admin access publicly.
- A local headless-browser attempt was blocked by the execution environment's socket restrictions. The separate cloud browser could not reach localhost. No Lighthouse/CrUX or mobile visual score is claimed from those failed attempts. Preview/production browser checks will be recorded separately when reachable.

See the page-by-page validation JSON alongside this file for the exported URL/title/description/canonical inventory.

### Recorded local results

Production build succeeded on Next.js 15.5.29 / React 19. Both frontend and backend production dependency audits returned zero advisories. Export validation passed for 337 HTML pages, 333 sitemap URLs and 34,591 internal link/asset references. There are 326 frontend/catalog/model tests and 5 backend/notification tests; all passed.

The final local homepage HTML was **93,026 bytes**, versus **279,687 bytes** fetched from the original live page: about **66.7% less uncompressed HTML**. Initial tool-card links fell from 295 to 53. This is a payload/DOM measurement, not a measured improvement in LCP, INP, CLS or rankings. The shared framework JS changed with the security upgrade.

Netlify preview validation caught `.d.mts` discovery as a separate function. Removed the declaration from the function directory and moved its test to the backend JavaScript suite; the real function remains `tool-embed.mjs`. Route type generation now runs before typechecking clean checkouts.
